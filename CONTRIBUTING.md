# Contributing

This local candidate is awaiting release review. Start with a small source lead
or a reproducible validation defect. Public-source evidence remains pending until
reviewed; research does not automatically publish questions, private locations or
conversation history. Show exact proposed records/method changes before opt-in.

Before building or scaling an adapter, inspect official API/bulk/export routes
and established clients; authentication, rights and actual quotas; schema, native
IDs, CRS, units, nulls, pagination and projections. Benchmark one bounded sample
and estimate requests, bytes, disk, time and cost with unknowns explicit. Separate
documented service limits from our guardrails. Reassess repeated manual steps,
slow assumed limits, full copies or unexpectedly slow checkpoint verification.

Known jobs must run ordinary deterministic code without an LLM. Preserve raw
evidence, source IDs (including leading zeros), quality flags and missingness.
Never merge by coordinates alone or infer drinking-water safety, yield or datum.
Run the offline README checks. Live jobs require explicit finite budgets and
must stop on denial, quota or validation failure; no automatic budget renewal.
